# Core patches

Every change we make to files that come from upstream FreeCAD is listed here, so upstream merges stay
predictable. New behavior should live in `src/Mod/Studio`; an entry here means no extension
point was available.

| Date | File(s) | Change | Why | Merge notes |

| 2026-11-19 | `src/Mod/Sketcher/Gui/DrawSketchHandlerLine.h`, `DrawSketchHandlerCircle.h`, `DrawSketchHandlerArc.h`, `DrawSketchHandlerPolygon.h`, `DrawSketchHandlerSlot.h`, `CommandCreateGeo.cpp` | New drawing methods in FreeCAD's sketch tools (each tool's panel list and the M key): Line **Center point** (the middle, then one end; a construction point in the middle, the ends Symmetric about it); Circle **2 rim points** (a diameter's ends); Arc **Tangent** (from the end of a line or arc, along its direction; end-to-end Tangent constraint); Polygon **Circumscribed** (the second click the middle of a side; a second construction circle touching it holds the size) and **Edge** (two corners, the polygon on the left, as AutoCAD); Slot **Overall** (end to end; a construction centerline carries the length) and **Center point** (the middle, one arc's center). Circle and Arc get their own method enums (`CircleConstructionMethod`, `ArcConstructionMethod`, first two values as the shared `CircleEllipseConstructionMethod`, which the ellipse keeps); Polygon and Slot get one each; `CommandCreateGeo.cpp` names the new enums for the 3-point circle and arc commands. Typed sizes become constraints as in the existing methods | The user asked for Fusion's, Inventor's and AutoCAD's ways to draw (PLAN 3.12, [SKETCH_TOOLS.md](SKETCH_TOOLS.md)) and approved this core edit on 2026-11-19. Studio can't add them itself: the tools' panel class (`SketcherToolDefaultWidget`) isn't exported from SketcherGui. Covered by `StudioTests.gui.test_sketch_ways` (each way drawn by clicks and with typed sizes); FreeCAD's TestSketcherApp and TestSketcherGui still pass | Additive: new enum values at the end, new branches keyed on the method, the existing methods' code paths unchanged (except Polygon and Slot measuring typed sizes from the first click, which is the center or first point they already used). On conflicts, re-apply per tool; the method lists' order is what Studio's toolbar (`context_toolbar.WAYS`) indexes |
